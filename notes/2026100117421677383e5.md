BrowserViewModel.load records history only when the resulting page is PageState.Gemtext or PlainText, using the final URL after redirects; failures, input prompts, non-Gemini redirects, unsupported MIME types, certificate prompts and exceptions are never recorded, and back/forward (served from cached HistoryEntry pages) don't count as visits. Keys are Url.normalized() (GeminiUrl.kt): lowercase host, no explicit :1965, no fragment, root path. BrowsingHistory.suggest strips gemini:// from query and entries; prefix matches rank above substring matches (substring only for 2+ chars), then by count x recency weight (100/70/50/30/10 at 4/14/31/90 days), ties to the newest. A query that exactly equals the sole match returns nothing. The cap is 500 entries, evicting oldest lastVisited. HistoryStore is a dumb store; FileHistoryStore uses 'count epochSeconds url' lines (URL last, split limit 3) and shares File.writeTextAtomically with FileKnownHostsStore. historyStore is the last BrowserViewModel constructor parameter so existing positional calls (store, knownHosts, client) keep compiling.
