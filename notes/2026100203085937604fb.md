Scaffold default contentWindowInsets exclude the IME, so BrowserScreen applies imePadding() on the Scaffold itself (which also consumes the nav-bar inset while the keyboard is open, avoiding a double-padded bar). MainActivity sets window.isNavigationBarContrastEnforced = false so the BottomAppBar colour reaches the screen edge under 3-button navigation instead of the system scrim; the manifest sets adjustResize for the URL field. The content Box calls consumeWindowInsets(innerPadding) and lists take innerPadding as contentPadding, never as a parent padding modifier.
