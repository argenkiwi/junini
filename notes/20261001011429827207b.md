Persisting TOFU pins on Android needs a Context (filesDir), so there is no expect fun for the store. FileKnownHostsStore (jvmShared, one line per pin: host port sha256hex notAfterEpochSeconds, written via a temp file and atomic move) is built in MainActivity and the desktop main.kt and passed into App(knownHostsStore). App then passes it to BrowserViewModel through the viewModel factory. iOS, Web and previews fall back to InMemoryKnownHostsStore. platformGeminiTransport takes the KnownHosts instance so the transport and the ViewModel share the same pins.
