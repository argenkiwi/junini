Junini uses TOFU (issue #3). KnownHosts in commonMain pins the SHA-256 of the leaf certificate DER (not the SPKI) for each host:port. A match passes, an expired pin is replaced silently (this covers renewals), and a valid pin that does not match throws CertificateMismatchException before any request bytes are written. The user can then trust the new certificate (KnownHosts.trust) or cancel. The JVM TofuTrustManager calls verify from checkServerTrusted. Ktor wraps whatever that throws, so the trust manager stores the mismatch in a field and fetch() rethrows it in place of the wrapped error. CertificateMismatchException extends GeminiException, which is now open.
