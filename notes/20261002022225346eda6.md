URLBuilder(base).takeFrom(ref) keeps the base parameters: a path-only or absolute reference inherited the old query, and a ?new reference produced ?old&new. After answering a Gemini input prompt the page URL carries the answer as its query, so any link or redirect to a query-less URL silently re-sent it. resolveUrl now clears the parameters before takeFrom unless the reference is empty or fragment-only (RFC 3986 5.2.2). Separately, PageState.Input carries an attempt counter because the sheet keys its text on the page, and an identical re-prompt would otherwise keep the typed text.
