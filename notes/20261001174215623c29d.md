The URL bar lives in a bottom BottomAppBar with exitAlwaysScrollBehavior, so a dropdown must open upwards and track the bar and the IME. Instead of a Popup/ExposedDropdownMenuBox (whose up/down placement depends on available space and which can fight the TextField for focus), SuggestionList is drawn inside the Scaffold content Box, aligned BottomCenter with padding(bottom = innerPadding.calculateBottomPadding()), so it always sits just above the bar. The best match is rendered last (closest to the field), so Up moves the highlight away from the field. Suggestion rows use focusProperties { canFocus = false } before clickable: the TextField dismisses suggestions on focus loss, and a row stealing focus would remove itself mid-click. While suggestions are visible, scrollBehavior heightOffset is reset to 0 so the bar can't slide away from the list.
