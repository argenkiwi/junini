Status 10/11 becomes PageState.Input(url, prompt, sensitive); BrowserScreen draws InputSheet (ModalBottomSheet) over an empty page. Answering calls load(url.withQuery(text)), where withQuery replaces the whole query and percent-encodes with %20, not + or key=value, as the spec requires. Input pages are excluded from backStack/forwardStack in load(), goBack() and goForward(), so Back after an answer returns to the page before the prompt and never to a stale prompt. Cancel and sheet dismissal reuse cancelCertificateChange(): go back if possible, else Idle. Unlike the suggestion list, the sheet is a popup window; the focus fights recorded for popups did not apply since the sheet owns its own field, but re-check on Android IME if the URL bar steals focus.
